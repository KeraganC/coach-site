# Brand notes

This template was derived from the current website source in the repository. The website code, rather than a generic slide theme, is the reference.

## Fonts found

- **Karla**, weights 400, 500, 600, and 700. Used for headings, body copy, navigation, buttons, labels, and the favicon monogram.
- **Caveat**, weight 600. Used sparingly for the site wordmark and Keragan's signature.
- The website loads both families from Google Fonts. The deck uses the same import and keeps system fallbacks so it remains usable when offline, though the exact Google fonts require a prior browser cache or internet connection.

## Primary colors

- Ink: `#2B2622`
- Soft ink: `#6B6058`
- Cream: `#FAF7F1`
- Deep cream: `#F3E9DA`
- Rust accent: `#D97757`
- Deep rust: `#A84F37`
- Fine borders: `rgba(43, 38, 34, 0.12)` on the site; slightly strengthened to `0.15` in slides for projection.

## Secondary colors

- Sage appears in the site's background wash as `rgba(127, 142, 115, 0.08)`. The slide system also uses its solid base, `#7F8E73`, where stronger projected contrast is needed.
- A restrained plum, `#73505F`, is an added supporting accent. It is used sparingly and sits comfortably with the site's warm neutral palette.

## Backgrounds

- Main paper-like background: `#FAF7F1`
- Deeper section and panel background: `#F3E9DA`
- The site's subtle rust and sage radial washes informed the deck's organic rings and paths. The deck avoids reproducing the web page background wholesale.

## Reusable visual motifs

- Small uppercase eyebrow labels in rust
- Fine warm borders and section rules
- Pill-shaped labels and buttons
- Softly rounded corners, generally 12px or less in the deck
- Circular portrait treatment and organic circular linework
- Rust and sage used as paired, non-judgmental accents
- Arrow-led lists
- Generous negative space and readable line lengths
- Caveat wordmark/signature as a warm handwritten counterpoint to Karla

## Assets reused

- `assets/favicon.svg`, copied from the main site for the browser tab
- `assets/keragan-photo.jpg`, copied into the template asset folder as an available example asset. It is not forced into a sample layout, so future editors can decide when a portrait is relevant.

## Treatments not carried into slides

- Sticky navigation and blurred header glass are web-navigation patterns, not presentation patterns.
- Hover lifts and web button animations are omitted except for simple timer-control feedback.
- The site's three-column workshop and newsletter grids are not treated as the default slide composition.
- Web-scale body type, long biographical paragraphs, and dense responsive sections would not remain readable from the back of a room.
- Photo overlays and tile gradients are not repeated because the sample system is primarily for reflective workshop facilitation, not content browsing.
