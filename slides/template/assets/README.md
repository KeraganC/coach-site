# Assets

Place workshop images in this folder and reference them with a relative path such as:

```html
<img src="assets/your-image.jpg" alt="A useful description of what the image shows">
```

Included from the website:

- `favicon.svg`: the KC browser icon
- `keragan-photo.jpg`: Keragan's portrait, available for an about or contact slide

Keep visible words as HTML rather than baking them into images.
